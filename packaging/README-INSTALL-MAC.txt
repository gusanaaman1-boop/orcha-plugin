ORCHA — macOS install
Rhythm Loop Generator · by Gussa Naaman · universal (Apple Silicon + Intel)

------------------------------------------------------------------------------
INSTALL
------------------------------------------------------------------------------

  1. Double-click  ORCHA-<version>-macOS.pkg
     It installs, and lets you deselect what you do not want:

       VST3        ->  /Library/Audio/Plug-Ins/VST3        (Cubase, Live...)
       Audio Unit  ->  /Library/Audio/Plug-Ins/Components  (Logic, GarageBand)
       ORCHA.app   ->  /Applications                       (standalone)

  2. If macOS refuses to open the .pkg ("unidentified developer"):
     RIGHT-CLICK the .pkg, choose Open, then Open again in the dialog.
     This build is ad-hoc signed, not notarized - that is the whole reason.

  3. In your DAW, rescan plugins. ORCHA is an INSTRUMENT, not an effect:
     add it on an instrument track. It appears under Naaman.

------------------------------------------------------------------------------
WHAT IT IS
------------------------------------------------------------------------------

Drop up to three samples. Click a sample's waveform to open the cutting room
(drag both edges, light fades). Pick the moment (DROP / BREAK / BUILD /
GROOVE) and the language (EDM / MELODIC TECHNO / PSYTRANCE / URBAN / BREAKS /
ARABIC / MEDITERRANEAN / AFRO / CINEMATIC / HYBRID), set the three macros,
and GENERATE LOOPS: twelve different options, synced to the project tempo.

On every card: play, favorite, re-roll (same groove, another take), EDIT
(step editor with velocity per hit + reverb/delay amounts), MIDI drag,
and DRAG - the loop lands in your DAW as a tempo-exact WAV.

------------------------------------------------------------------------------
REMOVE
------------------------------------------------------------------------------

Delete these and rescan:

  /Library/Audio/Plug-Ins/VST3/ORCHA.vst3
  /Library/Audio/Plug-Ins/Components/ORCHA.component
  /Applications/ORCHA.app
