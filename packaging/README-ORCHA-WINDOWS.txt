ORCHA
Rhythm Loop Generator  -  by Gussa Naaman  -  Windows x64

------------------------------------------------------------------------------
INSTALL - three steps
------------------------------------------------------------------------------

  1. EXTRACT this ZIP to a real folder. Right-click the ZIP, "Extract All".
     Do NOT run the installer from inside the ZIP viewer - Windows copies the
     .bat out on its own and then it has nothing to install.

  2. Close your DAW. Windows will not replace a plugin a running host holds.

  3. RIGHT-CLICK  INSTALL-ORCHA.bat  and choose "Run as administrator".

  That is it. No compiler, no downloads, about thirty seconds.

  Windows may show a blue "Windows protected your PC" box, because this
  plugin is not code-signed. Click "More info", then "Run anyway".

------------------------------------------------------------------------------
FIRST RUN
------------------------------------------------------------------------------

  Start your DAW and rescan plugins. In Cubase: Studio menu, then
  VST Plug-in Manager, then Update.

  ORCHA is an INSTRUMENT, not an effect - add it on an INSTRUMENT TRACK.
  It appears under Naaman.

------------------------------------------------------------------------------
WHAT IT DOES
------------------------------------------------------------------------------

Drop up to three samples on it - a kick, a snare, a hat, or any three sounds
you like. Pick which part of the track you are writing and which rhythmic
language it should speak. One click gives you twelve different loops, all
locked to your project tempo.

  DROP / BREAK / BUILD / GROOVE       what part of the track this is for
  EDM / MELODIC TECHNO / PSYTRANCE /  which rhythmic language it speaks
  URBAN / BREAKS / ARABIC /
  MEDITERRANEAN / AFRO / CINEMATIC /
  HYBRID
  ENERGY / DENSITY / RANDOMNESS       the three macros
  1 / 2 / 4 BARS                      loop length

  Press play on any card to hear it. The heart keeps a card when you
  regenerate. The circular arrow re-rolls just that one card, keeping its
  groove but changing the performance.

  DRAG a card straight into an audio track - it lands as a tempo-exact WAV.
  MIDI drags the same rhythm out as notes, for your own drum sounds.
  EDIT opens a step editor: click to add or remove hits, drag a hit up and
  down for velocity, and add reverb, delay or pump to that card alone.

  GENERATE MORE keeps your hearted cards and replaces the rest.
  DRAG CHAIN glues every hearted card into one continuous phrase.
  EXPORT ALL writes all twelve as WAV plus MIDI into a folder.

------------------------------------------------------------------------------
UNINSTALL
------------------------------------------------------------------------------

Right-click UNINSTALL-ORCHA.bat and choose "Run as administrator". It clears
every plausible location and says what it found in each.

------------------------------------------------------------------------------
KNOWN
------------------------------------------------------------------------------

Not code-signed, so Windows and some antivirus tools will warn on first run.
64-bit VST3 only - no VST2, no 32-bit.
